# Retail Data Engineering Platform

## Overview

This project is an end-to-end data engineering platform that demonstrates
batch processing and streaming data processing using modern data engineering
technologies.

## Components

- Python
- PostgreSQL
- SQLAlchemy
- Apache Airflow
- Apache Kafka
- Apache Spark
- Snowflake
- Docker
